# Command Cheat Sheet

Every agent on one page. In Claude, type the slash command or just say the phrase. In ChatGPT, Gemini or anywhere else, say the phrase or the agent's name.

## The two you need

| Slash | Or say | What happens |
|---|---|---|
| `/session-kickoff` | "catch me up" · "what's next" · "keep cranking" | Where things stand, next moves as clickable choices, and the right crew for each move |
| `/wrap` | "wrap it" · "log it" · "we done?" | Secret check, plain-English summary, log entry, commit note. One readout |

## The crew

| Slash | Or say | What happens |
|---|---|---|
| `/bvd` | "run it past the BVD" · "quick council" | 2–4 relevant seats review it, then a BVD readout |
| `/bvd` | "full council" · "all 11" · "roundtable" | All eleven seats review it separately (Claude Code), then a readout |
| `/vision-keeper` | "is this still what I wanted?" · "write the vision" | Checks a plan against VISION.md and hunts AI-invented rules, or writes VISION.md with you |
| `/checkpoint` | "checkpoint this" · "this is risky" | Restore point before risky work |
| `/checkpoint` | "roll back to <name>" | Undo back to a checkpoint, in one step |
| `/key-keeper` | "is anything leaking?" · "set up the hook" | Scans for API keys and passwords; installs the commit hook |
| `/qa-team` | "QA the site" · "is it really done?" | Smoke test with a keyboard pass, bug reports, hollow-feature grades |
| `/focus-group` | "playtest this" · "quick playtest with Pat and Lee" | Testers play it and report: Pat, Duke, Nadia, Grizz, Sam, Dale, Kai, Jax, Lee |
| `/focus-group` | "full playtest" · "demo weekend" | All nine testers, separately (Claude Code) |
| `/deploy-doctor` | "the deploy broke" · "check the latest deploy" | Reads Vercel logs, diagnoses, proposes the fix |
| `/asset-forge` | "I need art for..." | Style bible and art list, then Content Factory MAX's catalogue with drafted alt text (or a clickable prompt queue for ChatGPT) |
| `/content-factory-max` | "set up the content factory" · "set up the art factory" · "update the factory" | Installs Content Factory MAX (in-app pictures and sounds on one queue, AI cost tracker, Make art buttons) into the project, wired to its catalogue |
| `/translator` | "explain that" · "what did you change?" | Plain-English change report (the Wrap includes it) |
| `/scribe` | "status" · "overview" · "commit notes" | Log entries and status overviews (the Wrap includes it) |
| `/handoff-packer` | "pack it up" · "handoff for GPT" | A HANDOFF.md brief any tool can pick up cold |

## Shortcuts
- **"Light mode"**: small fix, no ceremony, one-line Wrap.
- **"Make it so" / "keep cranking"**: keep working through unblocked items until something needs Max.
- **Ask for a seat by name:** "what would George say?", "Henry, check this."
